# Assignment 2: Syntax, Semantics, and Memory Management

This repository contains the programs required for Assignment 2.

## Structure
- part1/python: Python syntax-error and type-system demonstrations
- part1/javascript: JavaScript syntax-error and type-system demonstrations
- part1/cpp: C++ syntax-error and type-system demonstrations
- part2/rust: Rust ownership/borrowing demonstrations
- part2/java: Java garbage-collection demonstration
- part2/cpp: C++ dynamic-memory and memory-leak demonstrations

## Important
Files named `syntax_error` or `ownership_error` intentionally contain errors for screenshot/analysis purposes.
Run the working versions separately.
